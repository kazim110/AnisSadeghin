# انیس الصادقین — نسخهٔ بازطراحی‌شده

پروژهٔ مستقل Android با Java و رابط بومی، راست‌به‌چپ و آفلاین. این پروژه از APK نسخهٔ ۳، محتوای کتاب و ساختار فهرست را استخراج کرده و رابط کاربری را از نو پیاده‌سازی می‌کند. سورس اصلی سازنده بازیابی نشده و فایل APK اصلی تغییر نکرده است.

## باز کردن و ساختن

پوشهٔ همین پروژه را در Android Studio با گزینهٔ Open باز کنید. SDK 35، Build Tools و JDK 17 یا جدیدتر لازم است. مسیر SDK در `local.properties` برای همین رایانه تنظیم شده است.

```bash
./gradlew assembleDebug
```

APK ساخته‌شده در `app/build/outputs/apk/debug/app-debug.apk` قرار می‌گیرد. یک کپی آماده نیز در `dist/AnisSadeghin-preview.apk` است. امضای این APK از نوع debug است؛ این خروجی برای آزمایش و استفادهٔ شخصی آماده شده است.

شناسهٔ برنامه `ir.anis.reader` است و کنار نسخهٔ اصلی با شناسهٔ `com.parsiblog.anis2` نصب می‌شود. حداقل نسخهٔ سیستم Android 6 است. ساخت پروژه به ابزارهای Gradle نیاز دارد؛ خود برنامه پس از نصب به اینترنت نیاز ندارد و هیچ مجوز ذخیره‌سازی، شبکه یا اعلان درخواست نمی‌کند.

## قابلیت‌ها

- صفحهٔ خانه با ادامهٔ مطالعه و دسترسی سریع به تعقیبات، دعاها و زیارات
- تمام ۳۶۶ مدخل اصلی، شامل ۳۳۱ متن قابل مطالعه و ۳۵ سرعنوان؛ ۲۵ مدخل در سطح اول فهرست
- جست‌وجوی چندواژه‌ای در عنوان و متن، با یکسان‌سازی «ی/ي/ى» و «ک/ك» و نادیده گرفتن اعراب، فقط در جست‌وجو
- نشانک‌گذاری و حذف نشانک با ذخیرهٔ محلی
- حفظ آخرین متن و محل پیمایش هر متن
- پیمایش متن قبل و بعد، اشتراک متن از طریق پنجرهٔ سیستم و انتخاب/کپی متن
- حالت شب، اندازهٔ قلم ۲۰ تا ۴۰ و انتخاب قلم میترا یا قلم سیستم
- اطلاعات اصلی کتاب، زندگی‌نامهٔ مؤلف و حقوق اثر
- حفظ صفحهٔ جاری هنگام چرخش دستگاه

متن‌های HTML در فایل داده عیناً حفظ شده‌اند. رنگ‌های نمایش نسخهٔ اصلی در صفحهٔ مطالعه برای خوانایی در زمینهٔ روشن و تیره تنظیم می‌شوند. داده‌های مطالعه و نشانک نسخهٔ قدیمی به نسخهٔ جدید مهاجرت داده نشده‌اند. فایل صوتی در APK منبع موجود نیست و این نسخه پخش‌کنندهٔ صوت ندارد.

## ساختار

- `app/src/main/java/ir/anis/reader/BookRepository.java`: خواندن داده، فهرست و جست‌وجو
- `app/src/main/java/ir/anis/reader/MainActivity.java`: صفحه‌ها، تنظیمات، مطالعه و نشانک‌ها
- `app/src/main/assets/book.json`: متن اصلی استخراج‌شده، همراه با معرفی و زندگی‌نامه
- `app/src/main/assets/fonts/`: قلم‌های موجود در APK منبع
- `tools/extract_content.py`: استخراج تکرارپذیر داده از APK
- `app/src/androidTest/`: آزمون روی دستگاه یا شبیه‌ساز، بدون وابستگی آزمایشی بیرونی
- `docs/REVERSE_ENGINEERING.md`: یافته‌ها و نتیجهٔ اعتبارسنجی

## آزمون روی شبیه‌ساز

برای جداسازی داده‌های آزمون از برنامهٔ اصلی جدید:

```bash
./gradlew -PverificationBuild assembleDebug assembleDebugAndroidTest
adb -s emulator-5554 install -r app/build/outputs/apk/debug/app-debug.apk
adb -s emulator-5554 install -r app/build/outputs/apk/androidTest/debug/app-debug-androidTest.apk
adb -s emulator-5554 shell am instrument -w ir.anis.reader.verification.test/ir.anis.reader.ReaderChecks
```

نتیجهٔ آخرین اجرا: **PASS: 66 checks**. بیلد عادی را بدون `-PverificationBuild` اجرا کنید.

## منبع و حقوق محتوا

کتاب و نرم‌افزار اصلی متعلق به صاحبان اثر هستند. متن کامل اطلاعیهٔ حقوق نسخهٔ اصلی در بخش تنظیمات ← دربارهٔ کتاب و برنامه نگه داشته شده است. این بازطراحی به عنوان نسخهٔ رسمی معرفی نمی‌شود. برای انتشار عمومی محتوا باید شرایط صاحب اثر بررسی و رعایت شود.

## تغییرات نسخهٔ ۱.۱

- نمایش هر شش تصویر اصل APK در موقعیت اصلی زندگی‌نامه
- صفحهٔ اختصاصی دربارهٔ مؤلف، با تب زندگی‌نامه و گالری تصاویر
- نمایش کامل هر عکس با لمس آن، بدون بریدن حاشیه‌های عکس‌های تاریخی
- صفحهٔ آغازین با عکس باکیفیت‌تر مؤلف، زمینهٔ سبز، قاب طلایی و گذار خودکار به کتاب
- هماهنگی زمینهٔ آغاز سیستم در Android 12 و جدیدتر، بدون آیکون اضافی کتاب
- فایل معرفی و تمام ۳۶۶ مدخل کتاب بدون تغییر حفظ شده‌اند

عکس صفحهٔ آغازین از [مصباح الصادقین](https://mesbah-sadeghin.ir/wp-content/uploads/2020/12/agha3.jpg) دریافت شده است (۱۴۲۷×۸۲۶ پیکسل). این عکس از همان جلسه/نمای دعای تصویر سوم زندگی‌نامه است؛ تصویر کم‌وضوح splash اصلی مستقیماً بزرگ‌نمایی نشده است. شش عکس تاریخی زندگی‌نامه از دادهٔ خود APK خوانده می‌شوند. برنامه هیچ تصویر را هنگام اجرا از اینترنت بارگیری نمی‌کند.

## تغییرات نسخهٔ ۱.۲

- معرفی مستقل برنامه بدون درج مشخصات شخصی بازطراح
- اشارهٔ روشن به برنامهٔ مبنا (انیس الصادقین نسخهٔ ۳ / سایت صادقین)
- حفظ انتساب کتاب و محتوای اصلی و دسترسی جدا به اطلاعیهٔ اصلی
- آیکون عکس‌دار با قالب adaptive و خروجی برای همهٔ تراکم‌های استاندارد Android
- ۹ تصویر منتخب از منابع اینترنتی، همراه با ۶ تصویر اصلی؛ مجموعاً ۱۵ عکس در گالری
- نمایش شبکه‌ای عکس‌های منتخب، نمایش کامل، بزرگ‌نمایی با دو انگشت/دوبار لمس و جابه‌جایی تصویر
- دکمهٔ قبلی/بعدی و پیوند صفحهٔ منبع در نمایش کامل عکس‌های منتخب
- تمام عکس‌ها در APK قرار دارند و آفلاین قابل مشاهده‌اند

فهرست منبع، ابعاد و SHA-256 عکس‌ها در `app/src/main/assets/gallery.json` آمده است. جزئیات حقوق و منبع در `docs/CONTENT_SOURCES.md` ثبت شده‌اند.
